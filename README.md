## 核心准则速览

### 1. 核心铁律
1. **画风统一声明**：全局、分镜与提示词中统一声明为 **“高级3D国漫建模，非真人实拍”**，严格禁用“半写实cg”。
2. **台词100%零删减（P0级）**：角色的每一句对白、每一声吐槽、每个关键细节必须完整逐字保留，严禁擅自删减、合并或概括。
3. **短剧极速快节奏（单镜1.5s-3.5s）**：动作起手即爆发，受力即反馈，绝无废镜头；纯空镜严格 ≤ 1.5秒（能带人带动作就绝不拍纯空景）。
4. **语速科学精算（杜绝掐字）**：按照影视常速 **3.2 ~ 3.5 字/秒** 精算镜头时长（公式：`单镜时长 = 字数 / 3.5 + 0.3s起息 + 0.3s留白`），超长台词顺着逗号句读拆为快速切镜，确保角色每个字清晰从容说完。
5. **场景与时间显式双锚定**：提示词全局设置首句必须明确【场景地点】与【具体物理时间光照】；分镜头切换必须显式声明【场景空间切换至：XXX】。
6. **空间防跳轴与左右死锁**：开镜定物理地标，镜头首句锁死左右站位（如“构图锁定：角色A居左、角色B居右”），视线量化夹角（+35°/-35°），180度轴线绝不颠倒。
7. **心声物理隔离**：遇到心理独白时，必须显式限制“双唇紧闭，绝不张嘴”，封死角色张嘴念心声的低级穿帮。
8. **动势剪辑（Cut-on-Action）与声画搭桥**：上镜结尾动作（60%~70%）顺接下镜开头爆发（70%~100%），J-Cut 拟音提前 0.2s~0.4s 铺设，对白间留出 0.2s~0.4s 呼吸微气口。
9. **单容器时长**：单个视频编号总时长在 **30.0秒内按戏剧自然定长**（约18s-28s，严禁死卡或注水凑数）。
