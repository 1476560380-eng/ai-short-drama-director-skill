# 短剧快节奏视听剪辑与台词语速科学精算规范

## 一、 短剧快节奏黄金法则
- **单镜黄金时长**：单个镜头的时长严格控制在 **1.5秒 – 3.5秒**（极特殊长爆发动作或长台词不超过 4.0秒）。
- **动作利落无死等**：起手即爆发，受力即反馈，动作与对白紧密嵌套，拒绝漫长蓄力与慢动作拖沓。
- **极限压缩空镜头**：定场或环境空镜压缩在 **1.0秒 – 1.5秒以内**（能带动作带人就绝不放纯空景）。
- **彻底消除无意义废镜头**：每一镜必须包含实质性的“因果推进”、“反差神态”或“物理动作”。
- **快节奏但绝对不删逻辑**：台词一句不少，剧情因果严丝合缝，依靠“快切对打”、“正反打紧凑交替”来提速。

## 二、 台词语速科学精算公式（杜绝掐字）
- 中文正常影视剧语速：**每秒 3.2 ~ 3.5 个汉字**。
- **单镜对白时长硬性底线公式**：
  $$\text{单镜台词所需秒数} = \frac{\text{纯汉字字数}}{3.5} + 0.3\text{s（起息前置）} + 0.3\text{s（收尾留白）}$$
- **超长台词处理原则**：遇到长台词时，顺着逗号句读拆为两个或多个快速切镜，确保角色每个字清晰从容说完，绝不掐字！
