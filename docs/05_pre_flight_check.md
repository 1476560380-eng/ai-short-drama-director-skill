# 生成前五重强制自检清单（Pre-flight Checklist）

在每次输出分镜和即梦一体化容器提示词之前，必须执行严格的内部五重核验：

1. **台词 100% 逐字对照检查（零删减、零篡改）**：角色名字对不对？每句对白是否完全保留？有没有擅自缩减或概括？
2. **动作受力因果与动势闭环检查（Cut-on-Action）**：上镜结尾 60%~70% 蓄力动势，下镜开头 70%~100% 顺势承接？受力反馈是否符合力学？
3. **空间轴线与站位防跳轴检查（180度轴线铁律）**：每镜首句是否焊死左右站位？连续镜头角色有无互换？视线夹角（+35°/-35°）是否对撞？
4. **声画卡点、呼吸气口与心声隔离检查**：每句台词后是否预留了 0.2s-0.4s 气口？心声是否强制双唇紧闭？
5. **画风与时长合规检查**：画风是否严格写为“高级3D国漫建模，非真人实拍”？单编号时长是否自然落在 30 秒内？
