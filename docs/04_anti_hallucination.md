# 空间防跳轴、人数硬锁定与心声物理隔离

## 一、 空间防跳轴与左右死锁
- **参考系锚定**：先选定场景物理地标（八仙桌、圆木桌、大理石柱、门槛）。
- **左右站位死锁**：在每个镜头的第一句就向模型锁死站位（例如“构图锁定：角色A居左、角色B居右”）。
- **视线夹角量化**：严格使用精确角度标识（如“视线：角色A右视左+35°，角色B左视右-35°”），强制模型保持摄影机处于轴线同一侧。

## 二、 严格人数硬锁定
- 每镜明确标注 `【总人数锁定：严格仅限X人（具名A、具名B）】`，杜绝任何未命名幽灵路人、随从入画。
- 层次化虚焦：有次要背景人物时，前清后虚，将多余人影弱化为景深模糊的氛围板。

## 三、 心声物理隔离（绝不张嘴）
- 遇到内心独白、系统心声、灵魂交流时，必须显式写入：`【心声隔离锁定】：双唇紧闭，喉结微动，绝不张嘴`。
