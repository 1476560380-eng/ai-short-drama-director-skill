# 即梦（Seedance）多镜一体化容器提示词准则

## 一、 生成推导过程（四步转化链路）
1. **结构降维与净化**：剔除表格审核中的冗余修辞、括号乱码与变量错位，仅保留最核心视听实体。
2. **时空连续性重构（0.0s–30.0s 全局绝对递增时间轴）**：将单镜内的相对时间戳全部折算为整个编号容器内的全局连续时间轴（如 [0.0s-4.5s] -> [4.5s-10.2s] -> [10.2s-18.0s]），确保拼接无缝且音画精准同步。
3. **分镜动线与空间物理校验**：补充前置力学动势（握拳蓄力、借转身势能、眼神先至后动手），绝不让动作凭空发生。
4. **即梦容器标准化封装**：统一封装为包含全局风格、分段镜头、时间戳音画同步与定向负面词的标准代码块，支持直接全选复制投喂。

## 二、 五大核心执行准则
1. **空间防跳轴与视线死锁**：
   - 参考系锚定：先选定场景物理地标（圆木桌、八仙桌、大理石柱）。
   - 左右站位死锁：镜头首句即锁死左右站位（如“构图锁定：角色A居左、角色B居右”）。
   - 视线夹角量化：精确标明视线矢量角度（如“视线：角色A右视左+35°，角色B左视右-35°”），绝不翻转轴线。
2. **动作受力因果与剪辑连贯性（Cut-on-Action & Physics）**：
   - 动势完整闭环：蓄力动作（60%~70%） -> 接触瞬间 -> 受力反弹与位移（70%~100%）。拒绝假动作或无过程倒地。
   - 环境交互物理反馈：拍桌震翻茶杯、跺脚鞋尖脆响、掌击立柱微颤等实物响应。
3. **声画严格卡点与呼吸气口（Sync & Breaths）**：
   - J-Cut 音效前置：开口前 0.3s–0.5s 铺设脚步、衣料摩擦、金铁摩擦等拟音。
   - 语速匹配：按中文正常语速（3.2–3.5字/秒）严密匹配台词时间段。
   - 显式呼吸气口：对白间或爆发前后硬性预留 [X.Xs-X.Xs]（气口0.2s-0.4s），为微表情留出窗口。
   - 心声物理隔离：遇到心理独白时，必须显式限定“嘴唇紧闭、喉结微动”，严禁张嘴念心声。
4. **人数硬锁定与防克隆（Crowd Control & Anti-Cloning）**：
   - 严格人数声明：每镜独立标明【总人数锁定：严格仅限X人（具名A、具名B）】。
   - 层次化构图：次要角色/随从采用“前景清晰对峙 + 后景深度虚焦”的大景深手法弱化为氛围板。
5. **画风纯净度与光照通明（Lighting & Style Guardrail）**：
   - 画风去真人化：全局强行声明“高级3D国漫建模，非真人实拍”，负面词压制 real human photos。
   - 杜绝黑屏暗场：无论情绪如何，场景强制环境通明补光，严禁暗场闪烁与过暗黑屏。
   - 零字幕纯净画面：彻底封杀台词水印字幕，保证成片画面绝对干净。
